# 개인정보

앱 안 '개인정보 처리방침' 화면(`features/settings/Settings.tsx`)과 같은 내용. 출시 전 법률 검토 권장.

| 정보 | 어디에 | 누가 보나 | 보관 |
|---|---|---|---|
| 닉네임 | 서버(공유 방) / 기기(한 기기 모드) | 같은 방 참여자 | 방 만료 시 삭제(당일 23:59 또는 12시간) |
| 예산·걷기 한도·먹고 싶은 것·못 먹는 것 칩 | 서버 / 기기 | 본인만 개별 값, 다른 사람은 그룹 요약 | 방 만료 시 삭제 |
| 투표 | 서버 / 기기 | 후보별 득표 수와 '투표 완료' 여부만 | 방 만료 시 삭제 |
| 익명 식별값 | 서버(`SHA-256(방키:토스 익명키)`) | 없음 | 방 만료 시 삭제 |
| **현재 위치** | **앱 메모리만**(저장·서버 전송 없음) | 본인 기기 | 앱 종료 시 사라짐 |
| 후보 식당 좌표 | 서버 / 기기 | 같은 방 참여자 | 방 만료 시 삭제 — 공공데이터 식당 위치(개인위치정보 아님). 도보 분은 각자 기기에서 자기 위치로 계산하고 저장하지 않음 |
| 내 기본 조건·최근 방·결정 기록 | 기기(토스 Storage / localStorage) | 본인 | 앱 삭제 또는 기록 지우기 |

- **수집하지 않음**: 알레르기·종교·건강 사유(민감정보), 실명, 전화번호, 위치 좌표(서버), 로그인 정보.
- **위치**: '내 위치로 찾기'를 누를 때만 권한 요청 → 기기 안에서 거리 계산에만 사용. 음식점 타일 파일을 받을 때 파일 서버(GitHub Pages) 접속 기록에는 대략 어느 칸(약 500m)을 요청했는지가 남을 수 있음. 위치정보지원센터 안내상 '단말기에서만 활용하고 사업자 시스템으로 전송하지 않는 경우'는 위치기반서비스사업 **비신고 대상**(D-041) — 출시 전 법률 검토로 최종 확인 권장.
- **외부 지도**: '카카오맵/네이버지도에서 보기'를 누르면 가게 이름·도로명 일부가 검색어로 그 서비스에 전달됨(사용자 위치는 전달하지 않음).
- 참여 전 "이 방 참여자와 서버에 공유돼요" 안내(`Join.tsx`).
- **이용 통계**: 방 만들기·참여·점심 결정의 이벤트 이름만 토스 통계로 보낸다(`Analytics.log`, SDK가 `anonymous_key`를 자동 포함, D-054). 위치·거리·식당·조건·닉네임은 넣지 않는다.
- 로그에 닉네임·조건을 남기지 않는다.
