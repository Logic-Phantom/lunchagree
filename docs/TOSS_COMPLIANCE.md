# 앱인토스 체크리스트 대응

사잇(2026-10-30 출시·검토 통과)과 같은 대응을 기본으로 한다. "확인" 열은 이 저장소 기준.

| 항목 | 대응 | 확인 |
|---|---|---|
| 라이트 모드만 | `color-scheme: light`, 다크 스타일 없음 | 브라우저 확인 |
| 핀치줌 비활성 | viewport `maximum-scale=1, user-scalable=no` | 구현 |
| 토스 내비게이션 바 사용, 뒤로가기 중복 금지 | `navigationBar.withBackButton`, 토스 안에서는 자체 뒤로가기 숨김(D-005) | 구현 · 토스앱 미확인 |
| 진입 즉시 바텀시트 금지 | 바텀시트는 사용자가 누를 때만 | 브라우저 확인 |
| 2초 이상 지연 금지 | 첫 화면은 로컬 데이터만, 후보 타일 요청 1.8초 타임아웃 → 직접 추가 안내 | 실데이터 데스크톱 336ms · 실기기 미측정 |
| 권한 사전 동의·거부해도 동작 | 클립보드 쓰기 + **위치(geolocation access)** 선언. 위치는 '내 위치로 찾기' 버튼에서만 요청하고 바로 위에 용도 안내, 거부 시 안내 문구 + 직접 추가로 계속 사용 | 브라우저 확인(거부 흉내) · 토스앱 미확인 |
| 자사 사이트 이동 금지 / 외부 이동 | 자사 사이트 없음. **카카오맵·네이버지도 장소 검색 링크**(`Device.openURL`) — 서비스 오픈 정책 2-2 '단순 정보 확인을 위한 타사 웹사이트 이동'(허용될 수 있는 경우), 체크리스트 61번 '꼭 필요한 외부 링크가 정상적으로 열려요'. 핵심 흐름은 앱 안에서 완결(D-042) | 문서 확인 · 토스앱 미확인 |
| 미니앱 간 이동 유도 금지 | 사잇 언급·링크 없음(데이터 출처 문구 제외) | 구현 |
| 광고를 추천처럼 위장 금지 | 결과 화면 하단 1개 + '광고' 표기(Phase 4, 현재 꺼짐) | 미착수 |
| 360px 가로 스크롤 없음 | 홈·방 만들기·결과·공유·설정·기록에서 scrollWidth = 360 | 브라우저 확인(2026-10-31) |
| 같은 워크스페이스 비슷한 앱 제한 | 사잇(중간역 찾기)과 핵심 기능이 다름 → 콘솔 설명에 차이 명시 | 콘솔 등록 시 |
