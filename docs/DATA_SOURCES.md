## Phase 0 결과

### 1. 음식점 원본 — 공식 API로 확정, 필드명 확인
- LOCALDATA가 2026-04-16 문을 닫고 공공데이터포털로 통합됐다. 15045016 파일 페이지의 다운로드 링크(`file.localdata.go.kr/...`)는 403이고, **원본을 받는 방법은 API 15154916뿐**이다.
- 호출 주소: `https://apis.data.go.kr/1741000/general_restaurants/info` (이력: `/history`, 2026-01-01 이후 기준일 조회)
- 요청 조건: `pageNo`, `numOfRows`(최대 100), `returnType=json`, `cond[SALS_STTS_CD::EQ]`, `cond[ROAD_NM_ADDR::LIKE]`, `cond[BPLC_NM::LIKE]`, `cond[OPN_ATMY_GRP_CD::EQ]`, `cond[LCPMT_YMD::GTE/LT]`, `cond[DAT_UPDT_PNT::GTE/LT]`
- 응답 필드 39개 중 저장하는 것(`column-map.ts`): `MNG_NO` 관리번호 · `BPLC_NM` 사업장명 · `SALS_STTS_CD/NM` 영업상태 · `DTL_SALS_STTS_NM` 상세영업상태 · `ROAD_NM_ADDR` 도로명주소 · `LOTNO_ADDR` 지번주소 · `CRD_INFO_X/Y` 좌표 · `BZSTAT_SE_NM` 업태구분명 · `SNTTN_BZSTAT_NM` 위생업태명 · `OPN_ATMY_GRP_CD` 개방자치단체코드 · `DAT_UPDT_PNT` 갱신시점.
  전화번호·종사자 수·보증액·월세 등은 버린다.
- 이전 코드의 한글 컬럼명(`사업장명`, `영업상태명`…)은 틀렸다 → 교체(D-032).

### 2. 좌표계 — 문서 표기가 모호해 실측 판정으로
- 포털 설명: "좌표계 : **보정계수 안들어간** Bessel 중부원점TM(**EPSG:5174**)". 그런데 EPSG:5174는 원점 경도에 10.405″ 보정이 들어간 정의이고, '보정 안 된' 중부원점은 보통 EPSG:2097이다(제3자 미러는 2097로 표기).
- 두 정의 차이는 서울에서 **동서 약 250m(도보 3~4분)** — 테스트로 확인.
- `npm run data:crs`: 도로명주소가 역사 주소와 같은 음식점(역 안 매장)을 역 좌표와 비교해 두 정의의 거리 중앙값을 낸다. 표본 ≥20 · 중앙값 ≤200m · 차이 ≥80m면 확정 → `reproject.ts` `SOURCE_CRS`. **키 받은 뒤 실행.**

### 3. 역 좌표 — 확보
- `npm run data:stations` → `fixtures/station-coords.json`: 사잇 581역 중 **578역**(노선별 역사 좌표 평균). 빠진 3곳: 도라산·동구릉·장자호수공원(원본에 없음).
- 동명이역: 사잇 이름의 괄호 힌트로 구분(양평 5호선 ↔ 양평(경의중앙선) 60km 떨어짐). 같은 역 노선별 좌표가 1km 넘게 벌어지면 제외 — 현재 0곳.
- 수도권·경춘선(강원)·1호선 충남 구간 주소만 사용(부산 '서면' 같은 다른 지역 동명이역 차단).
- 측정 역 10곳 좌표 예: 강남 37.497718, 127.027914 / 시청 37.564373, 126.976239 / 판교 37.395256, 127.111173.
- 수집 지역: 역사 주소에서 뽑은 **65개 시·군·구**(`fixtures/station-regions.json`, 서울 25개 구 전부). 원본 표기 차이(`서울시`, `충남`, `강원도`, 오타 `춘춘시`, 옛 이름 `인천시 남구`)를 현행 명칭으로 보정. 경기 시 아래 일반구는 개편이 잦아 시 단위로 묶음.
