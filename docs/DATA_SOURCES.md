## Phase 0 확인 항목 (원본을 받은 뒤 `npm run data:report`)
- [ ] 실제 컬럼명 → `data-build/src/column-map.ts` 갱신(현재 LOCALDATA 시절 표기, 미확인)
- [ ] 영업상태 값 목록 → `OPEN_STATUS_VALUES`
- [ ] 업태 값 목록 → `data-build/src/tag.ts` 표
- [ ] 좌표 결측률, EPSG:5174 변환 오차(알려진 주소 3곳, ≤ 30m)
- [ ] 갱신 주기
- [ ] 역 좌표 출처(공공누리 1유형 이상) → `data-build/fixtures/station-coords.json`
- [ ] 측정 역 10곳(제안: 강남·역삼·선릉·삼성·여의도·광화문·시청·을지로입구·판교·구로디지털단지)의 1km 후보 수 중앙값 ≥ 100, 종류 태그 확보율 ≥ 70%
  - 미달이면 "수동 후보 + 투표"만으로 MVP 범위를 줄이는 안을 보고(현재 앱은 이 모드로도 동작)
